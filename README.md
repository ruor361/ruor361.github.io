# Ruo

Ruo 的公开随笔、播客与 Vlog 主页。

- 站点：<https://ruor361.github.io>
- 技术栈：Astro + Firefly
- 本地开发：`pnpm install && pnpm dev`
- 完整校验：`pnpm check && pnpm type-check && pnpm build`

## 内容目录

- 随笔：`src/content/posts/`，frontmatter 使用 `category: 随笔`
- 播客：`src/content/posts/`，frontmatter 使用 `category: 播客`
- Vlog：`src/content/posts/`，frontmatter 使用 `category: Vlog`

## 身份边界

本站只使用 `Ruo <260375327+ruor361@users.noreply.github.com>` 提交，并且不复用其他站点的邮箱、头像、统计、评论或社交链接。

主题基于 [Firefly](https://github.com/CuteLeaf/Firefly)，Firefly 基于 [Fuwari](https://github.com/saicaca/fuwari) 二次开发。主题代码遵循仓库中的 MIT License。
